# COMP3612-Assignment2
COMP 3612 Assignment #2: Single-Page App in JavaScript
- Fetches from URL to retrieve products
- Displays categories and products with applicable filters and sorts. 
- Products can be added into cart, removed from cart, updated shipping prices
- Can inspect single products to see more information like description, specifications, related products, and reviews
